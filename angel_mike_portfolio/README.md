# Angel Mike — Personal Portfolio (Optimized)

A responsive personal portfolio built with **HTML, CSS, and vanilla JavaScript**. No Node.js, Python libraries, npm, or build tools are needed to run the website.

## Run the website in VS Code (Windows)

1. Unzip the folder.
2. In VS Code, select **File → Open Folder** and open `angel_mike_portfolio` (the folder that contains `index.html`).
3. Install the **Live Server** extension by Ritwick Dey (if not already installed).
4. Right-click `index.html` → **Open with Live Server**.
5. Your browser will open at an address such as `http://127.0.0.1:5500/index.html`.

**Alternative:** Double-click `index.html` to open it in a browser. The site is static and does not require a server. However, Live Server is easier for editing because it refreshes on save.

### Updating project details

The **project cards** are written in `index.html`. Their **expanded descriptions** are in the `projects` object at the top of `script.js`. Update both if the project changes. Each card has a `data-project` key matching a key in the JavaScript object.

### Updating colors

Edit the CSS custom properties in `:root` for the dark theme and `:root[data-theme="light"]` for light mode. For example, `--accent` is the site's primary accent color.

### Built-in interactions

- **Ctrl+K** on Windows/Linux or **Cmd+K** on Mac opens quick navigation. Type a section name, use up/down arrows, then press Enter.
- Click a project to see details; Enter or Space also works when a project card is focused.
- Use **All / Web / AI / ML / Learning** to filter projects.
- The light/dark theme selection is stored locally in the browser when storage is available.
- Mobile navigation and modal dialogs support the Escape key.
- The **Copy email** button uses browser clipboard access where available, and otherwise shows the address.

## What was optimized

- Moved font loading out of the stylesheet into preconnected HTML links, so CSS does not wait on a nested `@import` request.
- Applied the saved theme in the document head to reduce theme flash on page refresh.
- Cached frequently used DOM nodes and consolidated repeated listeners using event delegation.
- Throttled scroll-progress updates to animation frames and switched from element width changes to a transform.
- Avoided rebuilding quick-navigation results on every arrow-key press; results now update only when the search query changes.
- Improved mobile menu accessibility, project keyboard behavior, quick-navigation roles, theme labels, and dialog focus.
- Removed redundant CSS reveal declarations and reformatted the stylesheet so individual rules are easier to maintain.
- Preserved accessible content when JavaScript or motion effects are unavailable.

**Note:** These are code/design improvements, not a measured benchmark or a guarantee of a particular loading-speed gain. External Google Fonts are optional; local fallback fonts work offline.

## Publishing to GitHub Pages

1. Create a public repository on GitHub.
2. Upload the **contents** of the `angel_mike_portfolio` folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`.
4. Open the public URL generated by GitHub. No build command or output directory is required.

## Privacy and project status

The site does not include a home address, phone number, analytics, a database, or a contact-form backend. Project illustrations are **conceptual visualizations**, not screenshots of deployed systems. AcneSight is an academic prototype, not a medical diagnostic service, and NetWatch remains a learning project in progress.
